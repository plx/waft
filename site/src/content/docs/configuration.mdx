`waft` applies configuration in the following order. Later scalar values
override earlier values.

1. Built-in defaults.
2. User config: `~/.config/waft/config.toml`.
3. Project configs: each `.waft.toml` in the resolved source worktree, from
   its repo root down to the invocation directory's equivalent source path.
4. Environment variables using the `WAFT_*` prefix.
5. CLI flags.

`exclude.extra` arrays append across layers. Set
`exclude.replace_extra = true` or pass `--replace-extra-excludes` to discard
values from earlier layers.

Project configs must be regular files. Symlinked configs fail closed, and
discovery stops at nested repositories and registered submodules.

Selecting a profile resets its four settings at that layer. Explicit settings
in the same or a later layer can override it.

`--isolated` omits user configuration, `WAFT_CONFIG_PATH`, and `WAFT_*` policy
environment variables. Built-in defaults, source-project configuration, CLI
overrides, and operational Git backend selection still apply.

## Example `.waft.toml`

```toml
version = 1

[compat]
profile = "git"

[exclude]
extra = ["*.bak"]

[copy]
strategy = "auto"
```

## CLI overrides

| Option                                                       | Description                                               |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| `--compat-profile <claude\|git\|wt>`                         | Set the four profile-owned options.                       |
| `--when-missing-worktreeinclude <blank\|all-ignored>`        | Set behavior when no `.worktreeinclude` exists.           |
| `--worktreeinclude-semantics <claude-2026-04\|git\|wt-0.39>` | Select the matcher.                                       |
| `--worktreeinclude-symlink-policy <follow\|ignore\|error>`   | Set handling for symlinked rule files.                    |
| `--builtin-exclude-set <none\|tooling-v1>`                   | Select a built-in exclusion set.                          |
| `--extra-exclude <GLOB>`                                     | Add an exclusion. Repeat the option to add more than one. |
| `--replace-extra-excludes`                                   | Discard exclusions inherited from earlier layers.         |
| `--copy-strategy <auto\|simple-copy\|cow-copy>`              | Select plain-copy or copy-on-write behavior.              |
| `--config <PATH>`                                            | Replace user-config discovery with the specified file.    |
| `--isolated`                                                 | Omit user config and policy environment variables.        |
