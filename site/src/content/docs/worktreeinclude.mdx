Put `.worktreeinclude` at the root of the main worktree to select ignored
files for copying. The default `claude` profile uses `.gitignore`-style
patterns:

```text
# Local environment files
.env
*.env.local

# Except test environments
!test.env.local
```

This file selects files; it does not make Git ignore them. In this example,
`.env` and matching local environment files must already be ignored and untracked.

## Eligibility

A file is eligible for copying only when all of these are true:

1. It exists in the source worktree.
2. It is a regular file, not a symlink, directory, or special file.
3. It is selected by the active compatibility profile.
4. Git confirms it is ignored and untracked.
5. It is not removed by a built-in or configured exclusion.

## Profile-dependent matching

The default `claude` profile reads only the repository root
`.worktreeinclude`. The `git` profile composes nested `.worktreeinclude` files
like nested `.gitignore` files. The `wt` profile starts with every ignored,
untracked file and applies worktrunk-compatible exclusions.

Without a root `.worktreeinclude`, the default profile selects nothing.
See [Profiles](../profiles/) for the differences and how to choose one.

## Validation

Run `waft validate` to check rule-file syntax or `waft info .env` to see why a
particular file is selected or skipped.
