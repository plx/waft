## `claude`

`claude` is the default. It reads only the repository root
`.worktreeinclude` and matches the observed Claude Code behavior identified by
`claude-2026-04`.

```sh
waft copy --compat-profile claude
```

## `git`

`git` applies per-directory exclude semantics. Patterns are relative to the
directory containing the rule file, and deeper rule files override shallower
ones.

```sh
waft copy --compat-profile git
```

## `wt`

`wt` matches the observed behavior identified by `wt-0.39`. It starts with
every ignored, untracked file and removes paths matched by literal-name
negations.

```sh
waft copy --compat-profile wt
```
