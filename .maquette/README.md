# Archived Maquette artifacts

The files under `.maquette/` preserve an earlier design exploration. They are
archived and superseded by the canonical `design-system/` directory.

Do not use these artifacts as a source of truth for production site changes.
Read `design-system/SKILL.md` and `design-system/README.md`, then use
`design-system/colors_and_type.css`, `design-system/assets/`, and
`design-system/ui_kits/site/`. The deployable application remains under
`site/`.
